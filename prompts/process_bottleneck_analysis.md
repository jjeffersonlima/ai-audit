# Prompt: Workflow Bottleneck Identifier

**When to use:** After documenting a process, to analyze where automation fits.

**Prompt Template:**

```text
Analyze this process description and identify automation opportunities:

Process: [PASTE PROCESS DESCRIPTION]
Current time per execution: [HOURS/MINUTES]
Weekly frequency: [NUMBER]
People involved: [ROLES]
Tools used: [LIST]

Provide:
1. Top 3 bottlenecks causing delays or errors
2. Specific steps that could be automated with no-code tools
3. Estimated time savings per execution
4. Recommended no-code tool for each automation opportunity
5. Implementation complexity rating (Low/Medium/High)

Be specific about which tool (Zapier, Make, n8n, ChatGPT) fits each opportunity and why.
```
