# Legenda: Tabela `onboarding_responses`

Este documento serve como referência para interpretar os dados estruturados do questionário de onboarding.

| Coluna | Descrição |
|---|---|
| `id` | Identificador único do registro |
| `created_at` | Data e hora do envio |
| `company_name` | Nome da empresa |
| `website` | Site da empresa |
| `segment` | Segmento de atuação |
| `business_model` | Modelo de negócio (B2B, B2C, etc.) |
| `annual_revenue` | Faturamento anual |
| `years_in_market` | Tempo de mercado |
| `has_sales_manager` | Se possui gestor comercial |
| `team_bdrs` | Quantidade de BDRs |
| `team_sdrs` | Quantidade de SDRs |
| `team_closers` | Quantidade de Closers |
| `team_leaders` | Quantidade de Líderes |
| `team_others` | Quantidade de outros cargos |
| `funnel_stages` | Etapas do funil de vendas |
| `avg_sales_cycle` | Tempo médio do ciclo de vendas |
| `leads_per_month` | Quantidade de leads por mês |
| `conversion_rate` | Taxa de conversão |
| `avg_ticket` | Ticket médio |
| `cac` | Custo de aquisição de cliente |
| `ltv` | Lifetime value do cliente |
| `deals_per_month` | Negócios fechados por mês |
| `calls_per_day` | Ligações feitas por dia |
| `emails_per_day` | E-mails/mensagens enviados por dia |
| `meetings_per_week` | Reuniões por semana |
| `prospecting_time` | Tempo diário gasto em prospecção |
| `acquisition_channels` | Canais de aquisição utilizados |
| `channel_most_leads` | Canal que gera mais leads |
| `channel_best_quality` | Canal com leads de melhor qualidade |
| `channel_optimize` | Canal que otimizaria para bater metas |
| `prospecting_methods` | Métodos de prospecção ativa |
| `lead_list_methods` | Como geram listas de leads |
| `lead_nurturing` | Estratégia de nutrição de leads |
| `micro_processes` | Subprocessos detalhados por cargo (JSON) |
| `uses_crm` | Se utiliza CRM |
| `crm_name` | Nome do CRM |
| `crm_utilization` | Nível de utilização do CRM |
| `crm_integrations` | Integrações do CRM |
| `tools` | Ferramentas utilizadas (JSON) |
| `tech_adoption_level` | Nível de adoção tecnológica |
| `has_automations` | Se possui automações |
| `legacy_systems` | Sistemas legados em uso |
| `top_bottlenecks` | Principais gargalos do processo |
| `team_complaints` | Reclamações mais comuns do time |
| `lost_opportunities` | Principal motivo de perda de oportunidades |
| `time_waste_ranking` | Ranking de onde se perde mais tempo (JSON) |
| `automation_goals` | Objetivos de automação |
| `quick_win` | Quick win desejado |
| `additional_notes` | Observações adicionais |
